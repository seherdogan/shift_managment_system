# Vardiya Yönetim Sistemi (Shift Management System) 

Bir işletmenin personel vardiyalarını, lokasyonlarını ve atamalarını etkin bir şekilde yönetmek için geliştirilmiş **tamamen full-stack** bir web uygulaması.

---

# Proje Amacı
- Personel vardiyalarını kolayca planlama
- Kullanıcı rolleriyle yetkilendirme (admin, yönetici, personel)
- Lokasyon bazlı vardiya yönetimi
- Gerçek zamanlı atama ve takip
